# Changelog

All notable changes to The Developer Handbook are documented here.

The project uses tagged editions for stable publication artifacts and records continuous corrections through Git history. Version numbers follow [Semantic Versioning](https://semver.org/) as an edition-management convention.

### Added

## [1.0.0] — 2026-11-01

### Added

- First complete edition containing Chapters 1–129.
- Ten-part curriculum spanning Unix foundations, terminal workflow, Git, operating systems, networking, automation, containers, AWS, system design, debugging, performance, and observability.
- Engineering Patterns appendix connecting recurring principles across layers.
- Reproducible combined Markdown, standalone HTML, EPUB, DOCX, and PDF publication formats.
- Structural, link, Markdown, executable-example, and cross-book editorial validation.
